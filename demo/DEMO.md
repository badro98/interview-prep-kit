# Demo data (screenshots & walkthroughs)

Fictional sample candidate **Jordan Lee** interviewing for **Staff Software Engineer** at **Northwind Analytics**.

## Install into this repo

```bash
npm run demo:setup
npm run dev
```

## Install into a separate folder (e.g. for screenshots)

```bash
cp -R . ~/Desktop/interview-prep-demo
cd ~/Desktop/interview-prep-demo
npm install
cp /path/to/your/.env .env   # your Gemini key
npm run demo:setup
npm run dev
```

Open http://localhost:5173 — suggested tabs for README screenshots:

1. **Prep Docs** — Onsite stage (filled doc + notes)
2. **Flashcards** — card with coaching feedback visible
3. **Context** — multiple sources enabled
4. **Advisor** — optional if you send a message with API key

All data is fictional. Safe to publish in screenshots.
